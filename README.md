# Todo — Modern Task Manager

A modernized todo application built with **React 19**, **TypeScript**, **Vite**, **Redux Toolkit**, and **Tailwind CSS v4**.

## Features

- Add, edit (double-click), complete, and delete todos
- Undo delete via toast
- Filters (All / Active / Done), search, and sorting
- Priority levels and optional due dates with overdue highlighting
- Progress bar and stats, clear completed
- Light / dark theme with system preference
- Persistent storage via `localStorage`
- Smooth animations and responsive design

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173.

## Scripts

- `npm run dev` — start dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview production build
- `npm run lint` — lint
